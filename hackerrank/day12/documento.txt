ObjetivoHoy exploraremos la Herencia (Inheritance). Revisa el tutorial adjunto para obtener materiales de aprendizaje y un video instructivo.TareaSe te dan dos clases, Person y Student, donde Person es la clase base y Student es la clase derivada. El código completo para Person y la declaración para Student se proporcionan en el editor. Observa que Student hereda todas las propiedades de Person.Completa la clase Student escribiendo lo siguiente:Un constructor para la clase Student, el cual recibe 4 parámetros:Un string, firstName.Un string, lastName.Un entero, id.Un arreglo (o vector) de enteros con las calificaciones de las pruebas, scores.Un método calculate() que devuelve un char. Este método calcula el promedio del objeto Student y retorna el carácter de la letra correspondiente a su promedio según la siguiente escala:Rango del promedioLetra / Calificación (char)$90 \le \text{Promedio} \le 100$'O'$80 \le \text{Promedio} < 90$'E'$70 \le \text{Promedio} < 80$'A'$55 \le \text{Promedio} < 70$'P'$40 \le \text{Promedio} < 55$'D'$\text{Promedio} < 40$'T'Formato de entradaEl código base bloqueado en el editor lee la entrada y llama al constructor de la clase Student con los argumentos necesarios. También llama al método calculate(), el cual no toma argumentos.Primera línea: Contiene firstName, lastName e id, separados por un espacio.Segunda línea: Contiene el número de calificaciones del examen.Tercera línea: Contiene enteros separados por espacio que representan el arreglo scores.Restricciones$1 \le \text{longitud de } \text{firstName}, \text{longitud de } \text{lastName} \le 10$id tiene exactamente $7$ dígitos.$1 \le \text{número de calificaciones} \le 100$$0 \le \text{calificación} \le 100$Formato de salidaLa salida es manejada automáticamente por el código base. Tu salida será correcta si el constructor de la clase Student y el método calculate() están correctamente implementados.Entrada de ejemploPlaintextHeraldo Memelli 8135627
2
100 80
Salida de ejemploPlaintextName: Memelli, Heraldo

ExplicaciónEste estudiante tiene $2$ calificaciones para promediar: $100$ y $80$. La calificación promedio del estudiante es $(100 + 80) / 2 = 90$. Un promedio de $90$ corresponde a la letra 'O', por lo que el método calculate() debe retornar el carácter 'O'.
